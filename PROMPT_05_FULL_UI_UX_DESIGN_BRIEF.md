# Prompt 05 — Full UI and UX Design Brief

Create a design brief for the NHSCopilot-Eval aggregate catalogue.

Audience: technical reviewers, not clinicians seeking patient advice. Brand: restrained, transparent, research-first. Cover category/model/filter flow, aggregate tables, uncertainty, abstention and unavailable states, source/licence metadata, limitations, loading/error/empty states, accessibility, and offline behavior. Make the not-clinical-advice and no-endorsement disclaimer persistent. Never design live patient inference or raw-response display.
