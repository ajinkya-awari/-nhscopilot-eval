# Disclosure checklist

- [ ] Rights ledger reviewed for every admitted source.
- [ ] Public development projection contains no answer keys.
- [ ] Private authoring and sealed evaluation files are excluded from public output.
- [ ] Raw provider responses and hidden reasoning are absent from public artifacts.
- [ ] Secret and PHI scans have fresh evidence.
- [ ] BNF and restricted guideline text are absent.
- [ ] WHO/NHS code tables are not redistributed.
- [ ] Model snapshot, availability, cost, and parameters are recorded.
- [ ] not_run, refusal, abstention, timeout, malformed, and provider-error states remain distinct.
- [ ] Claims are manifest-linked and include uncertainty and limitations.
- [ ] Research-only and not-clinical-advice disclaimers are visible.
- [ ] Publication, deployment, email, and outreach have explicit approval.
