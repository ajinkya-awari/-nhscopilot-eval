# Prompt 13 — Write Clean Git Commits

Prepare NHSCopilot-Eval commits but do not create them until approval.

Separate provenance/dataset contracts, local baseline, scoring/analysis, tests, app, and deployment preparation. Use Conventional Commit subjects under 50 characters. Never include PHI, restricted source text, hidden labels, keys, `.env`, raw provider outputs, generated caches, fabricated metrics, or unreviewed public artifacts. Show staged files, exact messages, and rollback before committing. Never push automatically.
